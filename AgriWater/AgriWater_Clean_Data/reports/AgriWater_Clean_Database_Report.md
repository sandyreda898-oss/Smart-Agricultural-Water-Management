# تقرير قاعدة البيانات النظيفة - AgriWater

**تاريخ اللقطة:** 2026-10-25  
**قاعدة البيانات:** database/agriwater_clean.sqlite  
**النطاق:** بيانات الأرز في كفر الشيخ، مرحلة جمع البيانات وقاعدة العلاقات.

## ملخص التنفيذ

أنشئت حزمة منفصلة من قاعدة المشروع الأصلية دون تعديلها. تضم 44 جدولًا، 48 علاقة مفتاح خارجي، 461 عمودًا موثقًا و10 جداول فارغة. جرى تصدير 34 جدولًا غير فارغ إلى CSV/CSV.GZ. فحص SQLite: ok، ومخالفات المفاتيح الخارجية: 0.

## علاقة الجداول الأساسية

- district -> grid_point -> weather_daily / soil_point / soil_awc.
- season -> regional_stats / crop_calendar / point_season_summary / water_scenario.
- rice_variety -> reference / field guide / calendar / trial results / water scenarios.
- literature_study -> trial_result / trial_observation / environmental_measurement / evidence.
- field -> field_season -> irrigation_event / field_operation؛ جداول سجل الحقول خالية حاليًا.

راجع `schema/erd_all_tables.mmd` و`schema/foreign_key_relationships.csv` لكل العلاقات المستخرجة.

## بيانات إنترنت أضيفت في المراجعة الأخيرة

أضيفت ثلاث دراسات منشورة/جامعية إلى `literature_study` و`literature_evidence`: تجربة سخا لفترات الري والمسافات (2019-2020)، وتجربة سخا سوبر 300 لمواعيد الزراعة والنيتروجين وآفات الأرز (2019-2020)، وملخص جامعي لتحليل كفاءة الموارد لأصناف الأرز في كفر الشيخ (2020). تضيف هذه المصادر سياقًا عمليًا لمدخلات الصنف والتاريخ والمحصول السابق وإدارة المياه. أدخلت النتائج الملخصة فقط مع موضع المصدر وحالة البيانات؛ لا تمثل النتائج بيانات حقول مزارعين. تقدير توفير 1539 م³ في ملخص تحليل الكفاءة لا يوضح أساس المساحة، لذلك لا يحول إلى معدل للفدان أو زمن تشغيل مضخة. تفاصيل الصفوف وروابطها في تصديري `literature_study.csv` و`literature_evidence.csv` وسجل المصادر.

## مشكلات الأعمدة والجودة

التفاصيل لكل عمود في `schema/column_profile.csv` و`schema/data_dictionary.csv`. القضايا الرئيسة: نقص 1,292 قيمة طقس، 36/38 نقطة تربة مكتملة، جداول حقول وري فارغة، لا يوجد تصرف مضخة عند الرفع الفعلي، مناوبات الري غير متاحة، 7 قواعد وزارة ثانوية، 5 مراجع حماية نبات بلا جرعة/منتج، مدة سخا سوبر 300 متغيرة حسب تاريخ الزراعة، وإصدارات متعددة لسيناريوهات الماء. أضيفت دراسات منشورة ونتائجها بحالة مصدر واضحة، لكن نتائج التجارب وتقديرات تحليل الكفاءة ليست قياسات لحقول الفلاحين. النقص في أعمدة الدراسات الطويلة قد يكون طبيعيًا؛ لا تُحذف الأعمدة بسبب null% وحده.

## استخدام البيانات للموديل

المتاح كسمات: المكان، طقس شبكي، تربة خرائطية، خصائص صنف، تقويم/مرحلة، وبعض سياق المحاصيل السابقة. غير المتاح كأهداف تدريب ميدانية: حجم/عمق ري حقيقي، زمن تشغيل، غلة المزرعة، عمليات فعلية، تحليل التربة الخاص بالحقل، وتصرف المضخة. السيناريوهات المنشورة/المشتقة تصلح للمقارنة والتحقق الحسابي، لا لتدريب نموذج إشرافي كأنها نتائج مزارعين.

## بيانات لا يوفرها الإنترنت على مستوى الحقل

ريات كل حقل وغلاته، منسوب الماء الجوفي/ملوحة التربة بإحداثيات ومواعيد رصد زراعية، مناوبات الترع المحلية الحالية، موديل المضخة المركب وأداؤه عند TDH، توافر التقاوي محليًا، وتحليل NPK/EC الخاص بقطعة المستخدم. لا تُملأ هذه القيم بمتوسط المحافظة.
