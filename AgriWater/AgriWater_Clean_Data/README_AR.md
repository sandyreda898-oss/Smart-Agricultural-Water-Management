# حزمة بيانات AgriWater النظيفة

**النطاق:** قاعدة بيانات مرجعية منظمة للأرز في كفر الشيخ، موجهة للتحليل والبناء اللاحق. هذه الحزمة منفصلة عن ملفات المصدر الأصلية.

## نقطة البداية

- `database/agriwater_clean.sqlite`: نسخة موحدة من قاعدة SQLite الرئيسية، مع الجداول والعلاقات كما هي.
- `schema/schema.sql`: تعريف الجداول والقيود.
- `schema/erd_core.mmd`: رسم العلاقات الأساسية بصيغة Mermaid.
- `schema/erd_all_tables.mmd`: العلاقات المستخرجة من مفاتيح SQLite الخارجية لكل الجداول.
- `schema/data_dictionary.csv`: قاموس جميع الأعمدة والأنواع والمفاتيح والمصدر المرجعي وعدد القيم المفقودة/الفارغة ونطاق الأعمدة الرقمية.
- `schema/foreign_key_relationships.csv`: كل العلاقات الخارجية الـ48.
- `schema/column_profile.csv`: تقرير جودة لكل عمود.
- `schema/table_inventory.csv`: عدد الصفوف ووصف كل جدول.
- `data/table_exports/`: تصدير مطابق للجداول غير الفارغة؛ الجداول الكبيرة مضغوطة gzip لتقليل المساحة.
- `metadata/source_registry.json`: سجل المصادر وحدود الاستخدام.
- `metadata/data_quality_issues.csv`: قائمة المشكلات وقواعد التعامل معها.
- `reports/AgriWater_Clean_Database_Report_Updated.pdf`: التقرير التفصيلي المحدّث بعد إضافة الدراسات المنشورة.

## ماذا تعني كلمة "نظيفة" هنا؟

التنظيف هنا يعني قاعدة موحدة، مفاتيح وعلاقات سليمة، وتصديرات مولدة من قاعدة البيانات نفسها، مع توثيق الوحدة والمصدر والنواقص. لم أملأ قيمًا مفقودة بالتخمين ولم أدمج متوسطات الدراسات كأنها قياسات حقول. سجلات المصدر الثانوي أو الافتراضي باقية مع حالة الجودة ليقرر مستخدم النموذج إدراجها أو استبعادها.

## ملخص اللقطة

- 44 جدولًا، 48 علاقة بمفتاح خارجي، و461 عمودًا موثقًا.
- 34 جدولًا غير فارغًا له تصدير CSV/CSV.GZ.
- الطقس: 38 نقطة × 8 متغيرات يومية من 2017-01-01 إلى 2026-10-25، وعدد القيم NULL = 1292.
- سلامة SQLite: `ok`؛ مخالفات المفاتيح الخارجية: 0.
- الجداول الفارغة: canal_schedule، crop_history، field، field_operation، field_season، groundwater_level، irrigation_event، pump_type، soil_salinity، vegetation_index.

## تشغيل سريع

يمكن فتح `database/agriwater_clean.sqlite` مباشرةً باستخدام SQLite. لا تبدأ تدريب نموذج قبل قراءة `reports/AgriWater_Clean_Database_Report_Updated.pdf` وملف `schema/data_quality_issues.csv`، واختيار جداول السمات والهدف المناسبين.

## المخطط التحليلي النجمي (Star Schema)

أُضيفت طبقة تحليلية منفصلة لتسهيل الاستعلام والتحليل وبناء خصائص النموذج. قاعدة المصدر الموحدة أعلاه لم تُعدّل؛ طبقة النجمة مشتقة منها ويمكن إعادة بنائها عبر ETL.

- `warehouse/agriwater_star.sqlite`: قاعدة التحليل ذات الأبعاد والحقائق.
- `etl/build_star_schema.py`: كود التحويل وإعادة البناء؛ يشغّل من مجلد المشروع الرئيسي بالأمر `python AgriWater_Clean_Data/etl/build_star_schema.py`.
- `schema/star_schema.sql`: تعريف جداول وقيود طبقة التحليل.
- `schema/star_schema_overview.mmd`: رسم Mermaid للعلاقات بين الأبعاد والحقائق.
- `schema/star_fact_grain.csv`: تعريف مستوى التفصيل لكل جدول حقيقة؛ راجعه قبل أي ربط أو تجميع حتى لا تتكرر الصفوف أو تتضخم المجاميع.
- `metadata/star_etl_profile.csv`: أعداد المصدر والوجهة، وقواعد التحويل، وملاحظات الجودة.
- `metadata/manual_review_queue.csv`: عناصر محددة تحتاج مراجعة مرجعية يدوية قبل تحويلها إلى توصيات ميدانية.
- `metadata/star_schema_summary.json`: أعداد الجداول والصفوف ونتيجة سلامة القاعدة.
- `reports/AgriWater_Star_Schema_Final_Report.pdf` و`.md`: التقرير النهائي المفصل، بما فيه شرح التصميم، حدود البيانات، استخدامات النموذج، واستعلامات البداية.

تحتوي الطبقة على 17 بُعدًا و27 جدول حقيقة و5 عروض قراءة؛ وتتضمن 1,089,840 سجل طقس يومي و14,364 سيناريو مياه موسميًا. جداول الحقل وأحداث الري والعمليات الزراعية فارغة حاليًا لأنها تحتاج سجلات فعلية لكل حقل وموسم. لا تُعامل سيناريوهات المياه المحسوبة أو بيانات الدراسات كقياسات فعلية لحقل بعينه.

### ملاحظات قبل الاستخدام

- قيم الري الموسمية تقديرات/سيناريوهات مشتقة، وليست توصية نهائية بمدة تشغيل المضخة؛ يلزم تصريف المضخة الفعلي عند ضغط/رفع التشغيل لمعرفة الزمن.
- لا تُدرّب نموذجًا إشرافيًا للإنتاجية أو موعد الري على صفوف لا تحتوي هدفًا موثقًا. دراسات التجارب تصلح للمقارنة والتحليل ضمن سياق الدراسة، لا باعتبارها سجلًا مباشرًا لحقول المزارعين.
- مراجعة `manual_review_queue.csv` مطلوبة خصوصًا لوحدات بعض خواص التربة، والتحقق من قواعد الوزارة، واكتمال مرجعيات وقاية النبات، ومطابقة سلاسل المضخات لنقطة التشغيل.
- ملفات NDVI/EVI غير مستوردة إلى طبقة التحليل؛ المتاح بيانات فهرس مشاهد الأقمار فقط.
